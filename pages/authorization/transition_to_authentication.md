# OAuth2 vs OIDC

**O**pen**ID** **C**onnect standardise **l'authentification des utilisateurs par-dessus OAuth2**.
<br>
Il harmonise la façon de **récupérer les ressources liées à l'utilisateur** (profil, email, etc.)

# O<u>ID</u>C

Vous pouvez faire de **l'authentification avec OAuth2**, <br> mais les données utilisateur sont renvoyées de façon **non standardisée**.
<br><br>
**OIDC** standardise cela avec le concept d'**ID tokens** <br> qui fournissent les informations utilisateur dans un format cohérent.
